LEXO (**L**ocal **EX**traction and **O**CR) က PDF နဲ့ ပုံတွေကို ပြင်ဆင်နိုင်တဲ့ စာသားအဖြစ် ပြောင်းပေးတဲ့ Desktop app နဲ့ CLI ဖြစ်ပါတယ်။ မြန်မာစာကို ဦးစားပေးထားတာကြောင့် OCR ဘာသာစကားကို မြန်မာစာအဖြစ် မူလကတည်းက သတ်မှတ်ထားပါတယ်။ ထုတ်ယူထားတဲ့ စာသားကို Unicode NFC စံပုံစံနဲ့ ညီအောင် ပြင်ဆင်ပေးပြီး မြန်မာဖောင့်လည်း ပါဝင်တာကြောင့် စက်တိုင်းမှာ စာသားကို ဖတ်ရှုစစ်ဆေးရ လွယ်ကူပါတယ်။

## စာသား ရယူနိုင်တဲ့ နည်းလမ်း နှစ်မျိုး

LEXO က စာမျက်နှာတစ်ခုချင်းအတွက် သင့်တော်တဲ့ နည်းလမ်းကို ရွေးပေးပါတယ် -

- **Text layer (Text layer)** - Word သို့မဟုတ် InDesign ကနေ ထုတ်ထားတဲ့ PDF တွေမှာ Text layer ပါပြီးသား ဖြစ်ပါတယ်။ LEXO က အဲဒီစာသားကို မူရင်းအတိုင်း ချက်ချင်း ကူးယူပေးပါတယ်။ အင်တာနက်နဲ့ အကောင့် မလိုပါဘူး။
- **Google Docs OCR** - စကင် PDF နဲ့ ပုံတွေမှာ ကူးယူနိုင်တဲ့ စာသားအစား စာမျက်နှာပုံတွေပဲ ပါဝင်ပါတယ်။ LEXO က စာမျက်နှာတစ်ခုချင်းကို ပုံအဖြစ် ပြောင်းပြီး **မိမိ Google အကောင့်** ဖြင့် Google Docs OCR သို့ ပို့ဖတ်ကာ စာသားကို ပြန်ယူပေးပါတယ်။

ဖိုင်တစ်ခုတည်းတွင် နှစ်မျိုးလုံး ရောနေလည်း LEXO က စာမျက်နှာအလိုက် ခွဲခြား လုပ်ဆောင်ပေးပါတယ်။

## လိုအပ်ချက်များ

| | Text layer နှင့် PDF ကိရိယာများ | Google Docs OCR |
|---|---|---|
| Python 3.11 နှင့်အထက် | လိုတယ် | လိုတယ် |
| အင်တာနက် | မလို | လိုတယ် |
| Google အကောင့် | မလို | လိုတယ် |
| Google Cloud ကို တစ်ကြိမ် ပြင်ဆင်ခြင်း | မလို | လိုတယ် |

Google Cloud ပြင်ဆင်နည်း အဆင့်ခြောက်ဆင့်ကို [Google Cloud OAuth လမ်းညွှန်](/my/docs/google-cloud-setup/) မှာ ဖတ်နိုင်ပါတယ်။

## အမြန် စတင်အသုံးပြုရန်

1. [LEXO ကို ထည့်သွင်းပါ](/my/docs/installation/) -

   ```bash
   uv tool install lexo
   ```

2. စာသားပါ PDF တစ်ခုဖြင့် စမ်းကြည့်ပါ။ အကောင့်မလိုပါ -

   ```bash
   lexo extract report.pdf -o report.txt
   ```

3. စကင်ဖိုင်များအတွက် [Google Cloud ပြင်ဆင်မှု](/my/docs/google-cloud-setup/) ပြီးအောင်လုပ်ပြီး တစ်ကြိမ် အကောင့်ဝင်ပါ -

   ```bash
   lexo login
   ```

4. Desktop app ကို ဖွင့်၍ စာရွက်စာတမ်း တစ်ခုကို လုပ်ဆောင်ကြည့်ပါ -

   ```bash
   lexo gui
   ```

   ဖိုင်ဖွင့်ပြီး စာမျက်နှာတွေကို ပြင်ဆင်ပါ။ **Text layer** သို့မဟုတ် **Google Docs OCR** ကို ရွေးပြီး **Run** နှိပ်ပါ။ ရလာတဲ့စာသားကို စစ်ဆေးပြီး ဖိုင်အဖြစ် သိမ်းပါ။ အက်ပ်ရဲ့ အစိတ်အပိုင်းတစ်ခုချင်းကို [Desktop app လမ်းညွှန်](/my/docs/desktop-app/) မှာ ရှင်းပြထားပါတယ်။
