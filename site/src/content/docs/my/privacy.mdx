LEXO ရဲ့ လုပ်ဆောင်ချက်အများစုကို မိမိကွန်ပျူတာထဲမှာပဲ လုပ်ပါတယ် (**Local-first**)။ Google Docs OCR မသုံးသရွေ့ စာရွက်စာတမ်းတွေကို အပြင်မပို့ပါဘူး။ OCR သုံးတဲ့အခါတော့ အင်တာနက်လိုပြီး မိမိ Google အကောင့်မှတစ်ဆင့် Google ဆီ ပို့ဖတ်ပါတယ်။

## Google Docs OCR မသုံးရင် စာရွက်စာတမ်းတွေကို အပြင်မပို့ပါဘူး

အောက်ပါ လုပ်ဆောင်ချက်တွေက အင်တာနက်မလိုပါဘူး -

- PDF နှင့် ပုံများ ဖွင့်ခြင်းနှင့် Preview ကြည့်ခြင်း
- စာမျက်နှာ ဖြတ်တောက်ခြင်း၊ ခွဲခြင်း၊ လှည့်ခြင်း၊ ပေါင်းခြင်း၊ ထုတ်ယူခြင်းနှင့် အစီအစဉ်ပြောင်းခြင်း
- PDF ထဲမှာ ပါပြီးသား စာသား ထုတ်ယူခြင်း
- စစ်ဆေးခြင်း၊ ပြင်ဆင်ခြင်းနှင့် ဖိုင်အဖြစ် သိမ်းခြင်း

`lexo check-update` (သို့မဟုတ် **Check for Updates…**) ကို မိမိကိုယ်တိုင် သုံးတဲ့အခါမှာတော့ နောက်ဆုံးဗားရှင်းနံပါတ်ကို သိဖို့ PyPI ဆီ ဆက်သွယ်ပါတယ်။

## Google Docs OCR သုံးရင် - ဘာပို့သလဲ၊ ဘယ်ကိုပို့သလဲ

OCR လုပ်မယ့် စာမျက်နှာတစ်ခုစီကို LEXO က အောက်ပါအတိုင်း လုပ်ဆောင်ပါတယ် -

1. မိမိကွန်ပျူတာမှာ စာမျက်နှာပုံကို ပြင်ဆင်ပါတယ်။ PDF စာမျက်နှာတွေကို သတ်မှတ်ထားတဲ့ resolution ထက် မကျော်တဲ့ JPEG ပုံအဖြစ် ပြောင်းပါတယ်။
2. အဲဒီပုံကို **မိမိ Google Drive** သို့ တင်ပို့ပြီး OCR ပါတဲ့ Google Doc အဖြစ် ပြောင်းပါတယ်
3. ဖတ်ရလာတဲ့ စာသားကို ပြန်ယူပါတယ်
4. မိမိ Drive မှ ယာယီဖိုင်ကို ဖျက်ပါတယ်

စာမျက်နှာပုံတွေကို Google ဆီ ပို့ရတဲ့အတွက် မိမိ Google အကောင့်ရဲ့ စည်းကမ်းချက်တွေ အကျုံးဝင်ပါတယ်။ Google ဆီ တင်ပို့ခွင့်မရှိတဲ့ စာရွက်စာတမ်းတွေကို OCR မလုပ်ပါနဲ့။

ယာယီဖိုင်ကို ပြန်ဖျက်ဖို့ LEXO က ကြိုးစားပေးပေမယ့် အမြဲအောင်မြင်မယ်လို့ အာမမခံနိုင်ပါဘူး။ OCR အောင်မြင်ပြီး ဖိုင်ဖျက်တဲ့အဆင့်မှာ မအောင်မြင်ရင် Drive ထဲမှာ ယာယီဖိုင် ကျန်နိုင်ပါတယ်။ အဲဒီဖိုင်ကို မိမိကိုယ်တိုင် ဖျက်နိုင်ပါတယ်။

## drive.file ခွင့်ပြုချက်

LEXO က `https://www.googleapis.com/auth/drive.file` ခွင့်ပြုချက်တစ်ခုတည်းကိုသာ တောင်းပါတယ်။ ဒီခွင့်ပြုချက်နဲ့ **LEXO ကိုယ်တိုင် ဖန်တီးတဲ့ ဖိုင်တွေကိုသာ** ကြည့်နိုင်၊ ပြင်နိုင်ပါတယ်။ မိမိ Drive ထဲက အခြားဖိုင်တွေကို စာရင်းကြည့်တာ၊ ဖတ်တာ၊ ပြင်တာ မလုပ်နိုင်ပါဘူး။

## ကိုယ်ပိုင် OAuth Client

OAuth client ကို မိမိ Google Cloud project မှာ ကိုယ်တိုင် ဖန်တီးရပါတယ် ([ပြင်ဆင်နည်း](/my/docs/google-cloud-setup/))။ LEXO ဆာဗာကို ကြားခံမသုံးဘဲ အက်ပ်က Google နဲ့ တိုက်ရိုက် ဆက်သွယ်ပါတယ်။ LEXO အကောင့်ဖွင့်ဖို့ မလိုသလို အက်ပ်ကနေ အသုံးပြုမှုအချက်အလက် ကောက်ယူတာ၊ ခွဲခြမ်းစိတ်ဖြာတာလည်း မလုပ်ပါဘူး။

## Token ကို ဘယ်မှာ သိမ်းသလဲ

`lexo login` ဖြင့် အကောင့်ဝင်ပြီးရင် OAuth token ကို `keyring` library မှတစ်ဆင့် OS ရဲ့ keychain မှာ သိမ်းပါတယ်။ Windows မှာ Credential Manager၊ macOS မှာ Keychain၊ Linux မှာ Secret Service ကို သုံးပါတယ်။ `credentials.json` ဖိုင်ကို အကောင့်ဝင်တဲ့အချိန်မှာသာ ဖတ်ပါတယ်။

## ခွင့်ပြုချက် ပြန်ရုပ်သိမ်းခြင်း

- `lexo logout` (သို့မဟုတ် **Account → Sign out**) ဖြင့် Keychain မှ Token ကို ဖျက်ပါတယ်။
- Google ဘက်က ခွင့်ပြုချက်ကိုပါ ရုပ်သိမ်းချင်ရင် Google အကောင့်ရဲ့ Third-party connections မှာ ဖယ်ရှားပါ သို့မဟုတ် Cloud project ထဲက OAuth client ကို ဖျက်ပါ။

## ဒီဝက်ဘ်ဆိုက်

ဒီဝက်ဘ်ဆိုက်က အသုံးပြုမှုအချက်အလက် ကောက်ယူတာ၊ cookie သုံးတာ၊ ခြေရာခံတာ မလုပ်ပါဘူး။ မိမိရွေးထားတဲ့ အလင်း/အမှောင်ပုံစံနဲ့ ထည့်သွင်းနည်းကို ဘရောက်ဇာထဲက Local Storage မှာပဲ မှတ်ထားပါတယ်။
