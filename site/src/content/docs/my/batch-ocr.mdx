Batch OCR ဖြင့် PDF အများအပြားကို တစ်ဖိုင်ချင်း ဖွင့်ပြီး သိမ်းစရာမလိုဘဲ တစ်ကြိမ်တည်း လုပ်ဆောင်နိုင်ပါတယ်။ PDF တစ်ဖိုင်လျှင် UTF-8 `.txt` ဖိုင်တစ်ခု ထုတ်ပေးပါတယ်။ [Google Cloud ကို ကြိုတင်ပြင်ဆင်ထားပြီး](/my/docs/google-cloud-setup/) အကောင့်ဝင်ထားဖို့ လိုပါတယ်။

## Desktop app မှာ

အဖွင့်မျက်နှာပြင်ရှိ **Batch OCR PDFs** သို့မဟုတ် **File → Batch OCR PDFs…** (`Ctrl+Alt+O`) ကို ရွေးပါ။

1. ဖိုင်များ ရွေးရန် **Select PDFs…** သို့မဟုတ် Folder တစ်ခုရှိ PDF အားလုံးအတွက် **Use Folder…** ကို နှိပ်ပါ။
2. **Output folder** ကို ရွေးပါ။ မူလအားဖြင့် ပထမ PDF နဲ့ Folder တူထဲက `txt` Folder ဖြစ်ပါတယ်။
3. မြန်မာစာအတွက် **OCR language** ကို `my` အတိုင်း ထားပါ သို့မဟုတ် ပြောင်းပါ။
4. **Start OCR** ကို နှိပ်ပါ။

လုပ်ဆောင်မှု အခြေအနေပြ အကွက်မှာ ဖိုင်တစ်ခုချင်း၏ အခြေအနေကို ပြပြီး အချိန်မရွေး Cancel လုပ်နိုင်ပါတယ်။ Google အကောင့်ဝင်ထားမှု သက်တမ်း ကုန်သွားပါက LEXO က အကောင့်ဝင်ပြီး ဆက်လုပ်ဖို့ လမ်းညွှန်ပါတယ်။

## CLI မှ

Folder တစ်ခုထဲက PDF အားလုံး (Subfolder တွေထဲက ဖိုင်တွေ မပါပါ) -

```bash
lexo ocr-batch ./pdfs --out-dir ./txt
```

သတ်မှတ်ထားတဲ့ ဖိုင်များ -

```bash
lexo ocr-batch chapter-a.pdf chapter-b.pdf --out-dir ./txt
```

Command တစ်ခုတည်းမှာ ဖိုင်နဲ့ Folder တွေကို ရောပေးနိုင်ပါတယ်။ ဖိုင်တစ်ခုစီအတွက် `OCR:`၊ `wrote:` သို့မဟုတ် `skip:` ဖြင့် အခြေအနေကို ပြပြီး အဆုံးမှာ သိမ်းပြီးတဲ့ဖိုင်၊ ကျော်ထားတဲ့ဖိုင်နဲ့ မအောင်မြင်တဲ့ဖိုင် အရေအတွက်တွေကို အကျဉ်းချုပ် ပြပါတယ်။ ဖိုင်တစ်ခုခု မအောင်မြင်ရင် သုညမဟုတ်တဲ့ exit status ကို ပြန်ပေးပါတယ်။

## ရလဒ်ဖိုင်အမည်များ

ရလဒ်ဖိုင်မှာ မူရင်းဖိုင်အမည်ကို ထိန်းထားပြီး File extension ကိုသာ `.txt` သို့ ပြောင်းပါတယ်။ ဥပမာ၊ `chapter-a.pdf` အတွက် `txt/chapter-a.txt` ကို ရရှိပါမယ်။ Batch OCR က UTF-8 Plain text ကိုသာ ထုတ်ပေးပါတယ်။ Markdown သို့မဟုတ် JSONL လိုရင် ဖိုင်တစ်ခုချင်းအတွက် `lexo ocr` ကို သုံးပါ။

## ပြန်စခြင်းနှင့် ရှိပြီးသားဖိုင် အစားထိုးခြင်း

အမည်တူ `.txt` ဖိုင် ရှိပြီးသားဆိုရင် အဲဒီ PDF ကို **ကျော်ပေးပါတယ်**။ ဒါကြောင့် အလုပ်ရပ်သွားရင် ပြန်စရုံနဲ့ ပြီးသားဖိုင်တွေကို ကျော်ပြီး ကျန်တဲ့ဖိုင်တွေကို ဆက်လုပ်နိုင်ပါတယ်။

ရှိပြီးသား ဖိုင်များကို အစားထိုးရန် -

```bash
lexo ocr-batch ./pdfs --out-dir ./txt --overwrite
```

## Batch OCR မှာ ပါပြီးသား စာသားကို သုံးခြင်း

Batch OCR က မူလအားဖြင့် စာမျက်နှာတိုင်းကို ပုံအဖြစ် ပြန်ဖတ်ပါတယ်။ အများအားဖြင့် စကင်ဖိုင်တွေကို လုပ်ဆောင်ရတာဖြစ်ပြီး အချို့ဖိုင်တွေမှာ အရည်အသွေးမကောင်းတဲ့ OCR Text layer ဟောင်း ပါနေနိုင်လို့ ဖြစ်ပါတယ်။ PDF ထဲမှာ အသုံးပြုနိုင်တဲ့ စာသား ပါပြီးသားဖြစ်လို့ အဲဒီစာသားကို ထိန်းထားချင်ရင် -

```bash
lexo ocr-batch ./pdfs --out-dir ./txt --no-force-ocr
```

အက်ပ်ရဲ့ Batch OCR အကွက်မှာလည်း **OCR every page, even if it has embedded text** ဆိုတဲ့ ရွေးချယ်စရာ ရှိပါတယ်။

## Batch ကြီးများအတွက် အကြံပြုချက်

- PDF အားလုံးတွင် ဘေးလွတ်နေရာ တူညီပါက Batch မလုပ်မီ ဖြတ်တောက်ပြီး စာမျက်နှာခွဲထားပါ။ Batch OCR က စာမျက်နှာကို ဖြတ်တောက်မပေးပါဘူး။
- OCR အမြန်နှုန်းက အင်တာနက်နှင့် Google Drive ပေါ် မူတည်ပါတယ်။ LEXO က စာမျက်နှာ အနည်းငယ်ကို တစ်ပြိုင်နက် လုပ်ဆောင်ပြီး ခဏတာ မအောင်မြင်တဲ့ စာမျက်နှာများကို ထပ်မံကြိုးစားပါတယ်။
- မိမိ Google အကောင့်သို့ တင်ပို့ခွင့်ရှိတဲ့ စာရွက်စာတမ်းများကိုသာ Batch လုပ်ပါ။
