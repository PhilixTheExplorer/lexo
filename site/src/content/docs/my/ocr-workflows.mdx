LEXO မှာ ဖွင့်ထားတဲ့ စာမျက်နှာတွေက Text layer ပါတဲ့ စာမျက်နှာနဲ့ စာမျက်နှာပုံသာပါတဲ့ စာမျက်နှာဆိုပြီး နှစ်မျိုး ရှိပါတယ်။ အမျိုးအစားပေါ် မူတည်ပြီး စာသားရယူတဲ့ နည်းလမ်းလည်း ကွာခြားပါတယ်။

## Text layer နှင့် Google Docs OCR

| | Text layer | Google Docs OCR |
|---|---|---|
| သုံးနိုင်တဲ့ဖိုင် | စာသားပါ PDF | စကင် PDF၊ ပုံ |
| အမြန်နှုန်း | ချက်ချင်း | အင်တာနက်နှင့် Google ပေါ် မူတည် |
| အင်တာနက် | မလို | စာမျက်နှာပုံများကို မိမိ Drive သို့ တင်ပို့ |
| အကောင့် | မလို | မိမိ Google အကောင့် |
| တိကျမှု | PDF ထဲ သိမ်းထားတဲ့အတိုင်း | Google ၏ စာမျက်နှာပုံ ဖတ်ရှုမှု |

**အလွယ်ဆုံး ရွေးချယ်နည်း** - Text layer မှ ထုတ်ယူတဲ့နည်းကို အရင်စမ်းပါ။ စာသားမထွက်ရင် ဒါမှမဟုတ် မူရင်းနဲ့ မကိုက်ညီတဲ့ စာသားတွေ ထွက်လာရင် Google Docs OCR ကို သုံးပါ။

## Smart Routing အလုပ်လုပ်ပုံ

CLI မှာ `lexo ocr` က စာမျက်နှာတစ်ခုချင်းကို စစ်ဆေးပြီး နည်းလမ်းရွေးပေးပါတယ်။ အသုံးပြုနိုင်တဲ့ Text layer ပါရင် တိုက်ရိုက်ထုတ်ယူပြီး မပါရင် 300 DPI ပုံအဖြစ် ပြောင်းကာ OCR သို့ ပို့ပါတယ်။ ဥပမာ၊ စာသားပါတဲ့ အစီရင်ခံစာမှာ စကင်ဖတ်ထားတဲ့ နောက်ဆက်တွဲတွေ ပါနေရင် အစီရင်ခံစာရဲ့ စာသားကို တိုက်ရိုက်ထုတ်ပြီး နောက်ဆက်တွဲတွေကိုသာ OCR လုပ်ပေးပါတယ်။

စာမျက်နှာအားလုံးကို OCR လုပ်စေလိုရင် `--force-ocr` ကို ထည့်ပါ -

```bash
lexo ocr report.pdf --force-ocr -o report.txt
```

Desktop app မှာတော့ ရွေးထားတဲ့ နည်းလမ်းတစ်ခုတည်းကို လုပ်ဆောင်မယ့် စာမျက်နှာအားလုံးအတွက် သုံးပါတယ်။ **Google Docs OCR** ကို ရွေးရင် စာမျက်နှာပုံတွေကို ပြန်ဖတ်ပြီး **Text layer** ကို ရွေးရင် ပါပြီးသား Text layer မှ ထုတ်ယူပါတယ်။

## စကင်ဖတ်ထားတဲ့ PDF နှင့် ပုံများ

1. ဖိုင်ကို ဖွင့်ပါ သို့မဟုတ် **Select Image Set** ဖြင့် ပုံများကို ဖွင့်ပါ။
2. **Edit** Tab တွင် ခေါင်းစီးနှင့် စာမျက်နှာနံပါတ်များကို ဖြတ်တောက်ပြီး **PDF** Tab တွင် စာမျက်နှာနှစ်ခုတွဲ ပုံများကို ခွဲပါ။ မလိုအပ်တဲ့အပိုင်းတွေ ဖယ်ထားရင် OCR ရလဒ်မှာ အပိုစာသားတွေ နည်းသွားပါတယ်။
3. **Google Docs OCR** ကို ရွေး၍ **Run** နှိပ်ပါ။
4. စာမျက်နှာတစ်ခုချင်းကို မူရင်းပုံနှင့် ယှဉ်ဖတ်ပြီး လိုအပ်တာတွေ ပြင်ဆင်ပါ။
5. ဖိုင်အဖြစ် သိမ်းပါ။

CLI ဖြင့် -

```bash
lexo login
lexo ocr scan.pdf --lang my -o scan.txt
```

အချိန်ကြာတဲ့ အလုပ်တွေမှာ ယာယီချို့ယွင်းမှု ဖြစ်လာရင် မအောင်မြင်တဲ့ စာမျက်နှာကို အလိုအလျောက် ပြန်ကြိုးစားပေးပါတယ်။ မအောင်မြင်သေးတဲ့ စာမျက်နှာတွေကို အက်ပ်ထဲက **Retry Failed Pages** ဖြင့် သီးခြား ပြန်လုပ်နိုင်ပါတယ်။ ကြာချိန်က အင်တာနက်အမြန်နှုန်းနဲ့ Google Drive ရဲ့ တုံ့ပြန်ချိန်ပေါ် မူတည်ပါတယ်။

## ဖောင့်ဟောင်း PDF များ (Win Innwa၊ Win Myanmar)

Unicode မတွင်ကျယ်မီက မြန်မာစာကို Win Innwa၊ Win Myanmar လို ဖောင့်တွေနဲ့ ရိုက်လေ့ရှိပါတယ်။ ဒီဖောင့်တွေက **ASCII စာလုံးတွေကို မြန်မာစာပုံစံနဲ့ ပြသထားတာ** ဖြစ်ပါတယ်။ ဖိုင်ထဲမှာ သိမ်းထားတာက အင်္ဂလိပ်စာလုံးတွေဖြစ်ပြီး ဖောင့်ကြောင့်သာ မြန်မာစာအဖြစ် မြင်ရပါတယ်။

ဒီလိုဖိုင်ကနေ စာသားထုတ်ယူရင် ASCII စာလုံးတွေကိုသာ ရပါမယ်။ PDF ထဲမှာ သိမ်းထားတဲ့အတိုင်း ထုတ်ယူပေးတာဖြစ်ပေမယ့် မြန်မာစာအဖြစ် အသုံးပြုလို့ မရပါဘူး။

## Zawgyi ဖြင့် Encode လုပ်ထားတဲ့ စာသား

Zawgyi က မြန်မာ Unicode code point တွေကို စံနဲ့ မတူဘဲ သုံးထားတဲ့ အရင်က အသုံးများခဲ့တဲ့ encoding ဖြစ်ပါတယ်။ LEXO က Zawgyi ကို တိုက်ရိုက် မပြောင်းပေးပါဘူး။ PDF မှ ထုတ်ယူထားတဲ့ မြန်မာစာ ပုံပျက်နေရင် Zawgyi ဖြစ်နေနိုင်ပါတယ်။ Google Docs OCR ဖြင့် စာမျက်နှာပုံကို ပြန်ဖတ်ပြီး စံ Unicode စာသား ရယူနိုင်ပါတယ်။

## OCR ဘာသာစကား

ဘာသာစကား သတ်မှတ်ချက်ရဲ့ Default value မှာ မြန်မာ (`my`) ဖြစ်ပါတယ်။ အခြားဘာသာများအတွက် ဘာသာစကား သတ်မှတ်ချက်ကို ပြောင်းပါ -

```bash
lexo ocr scan.pdf --lang th -o scan.txt
```

`LEXO_OCR_LANGUAGE` ဖြင့်လည်း သတ်မှတ်နိုင်ပါတယ် ([ဆက်တင်များ](/my/docs/configuration/) ကို ကြည့်ပါ)။ ဘာသာစကား မှန်ကန်စွာ သတ်မှတ်ပေးရင် လက်တင်အက္ခရာ မသုံးတဲ့ အခြားဘာသာစကားတွေကိုလည်း Google Docs OCR က ဖတ်နိုင်ပါတယ်။ သို့သော် LEXO ကို မြန်မာစာအတွက် အဓိက ချိန်ညှိစမ်းသပ်ထားတာ ဖြစ်ပါတယ်။

## LEXO က စာသားကို ဘာလုပ်ပေးသလဲ

ထုတ်ယူပြီး သို့မဟုတ် OCR ပြီးနောက် LEXO က -

- စာသားကို Unicode **NFC** စံပုံစံနဲ့ ညီအောင် ပြင်ဆင်ပါတယ်။ အမြင်အားဖြင့် တူညီတဲ့ စာသားတွေကို တစ်သမတ်တည်း သိမ်းဆည်းနိုင်ဖို့ ဖြစ်ပါတယ်။
- မြန်မာ စကားလုံးနှင့် စာကြောင်းခွဲမှုကို ပြတဲ့ **Zero-width Space** (U+200B) များကို ထိန်းသိမ်းပါတယ်။
- မလိုအပ်တဲ့ control character နဲ့ မမြင်ရတဲ့ format character တွေကို ဖယ်ရှားပါတယ်။ ဆက်တိုက်ပါနေတဲ့ space တွေကို တစ်ခုတည်းဖြစ်အောင် ပြင်ပြီး စာကြောင်းအဆုံးက space တွေကို ဖယ်ရှားပါတယ်။

စာလုံးပေါင်း စစ်ဆေးခြင်း၊ စာပိုဒ်များ ပြန်စီခြင်း သို့မဟုတ် ကော်လံနှင့် ဇယား ကဲ့သို့ စာမျက်နှာအပြင်အဆင်များကို ခွဲခြားခြင်း မပြုလုပ်ပါဘူး။
