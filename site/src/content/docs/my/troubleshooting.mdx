## "Google OAuth client file not found"

LEXO က `credentials.json` ဖိုင်ကို ရှာမတွေ့တာ ဖြစ်ပါတယ်။ ဖိုင်ကို Config folder သို့မဟုတ် LEXO ကို စတင်လုပ်ဆောင်တဲ့ Folder ထဲမှာ ထားပါ။ Config folder ကို `lexo info` ဖြင့် ကြည့်နိုင်ပါတယ်။ `LEXO_GOOGLE_CREDENTIALS` မှာ File path ကို သတ်မှတ်ပေးလို့လည်း ရပါတယ်။ ဖိုင်အမည်ကို `client_secret_….json` အတိုင်း မထားဘဲ `credentials.json` ဟု ပြောင်းထားဖို့ လိုပါတယ်။ [Google Cloud ပြင်ဆင်နည်း](/my/docs/google-cloud-setup/) ကို ကြည့်ပါ။

## "Not signed in" သို့မဟုတ် "Your Google sign-in has expired"

`lexo login` ကို လုပ်ဆောင်ပါ သို့မဟုတ် အက်ပ်ထဲက **Account → Sign in with Google** ကို သုံးပါ။ OAuth အက်ပ်ကို Testing အဆင့်မှာ ထားရင် အကောင့်ဝင်ထားမှု သက်တမ်းက ၇ ရက်ခန့်ကြာရင် ကုန်ဆုံးတတ်ပါတယ်။ ဒါကြောင့် အကောင့်ပြန်ဝင်ရတာက ပုံမှန်ဖြစ်ပါတယ်။

Desktop app မှာ အကောင့်မဝင်ဘဲ OCR စရင် အကောင့်ဝင်ဖို့ လမ်းညွှန်ပြီး ပြန်လုပ်ပေးပါတယ်။

## Google က "This app isn't verified" ဟု ပြခြင်း

မိမိဖန်တီးထားတဲ့ OAuth အက်ပ်က Testing အဆင့်မှာ ရှိလို့ ဒီသတိပေးချက် ပေါ်တာ ဖြစ်ပါတယ်။ သတိပေးချက်ကို ကျော်ပြီး ဆက်လုပ်နိုင်ပါတယ်။ Test users စာရင်းမှာ ထည့်ထားတဲ့ အကောင့်တွေနဲ့သာ ဝင်နိုင်ပါတယ်။

## အကောင့်ဝင်ရာတွင် "access denied" ဖြစ်ခြင်း

မိမိ၏ Google အကောင့်ကို OAuth Consent Screen ရှိ **Test users** တွင် မထည့်ရသေးပါဘူး။ ထည့်ပြီး ထပ်ကြိုးစားပါ။

## စကင် PDF ကို ထုတ်ယူရင် စာသား မထွက်ခြင်း

စကင်ဖိုင်များတွင် Text layer မပါပါဘူး။ `lexo extract` က "looks scanned" လို့ ပြပါမယ်။ Google Docs OCR ကို သုံးပါ - `lexo ocr` သို့မဟုတ် App ကို **Google Docs OCR** သို့ ပြောင်းပါ။

## စာမျက်နှာက မြန်မာစာ ဖြစ်ပေမယ့် အင်္ဂလိပ်စာလုံးများ ထွက်ခြင်း

PDF ကို Win Innwa ကဲ့သို့ ASCII ဖောင့်ဟောင်းဖြင့် ရိုက်ထားခြင်း ဖြစ်ပါတယ်။ စာမျက်နှာကို ပုံအဖြစ် ဖတ်ရန် Google Docs OCR ကို သုံးပါ။ အသေးစိတ်ကို [OCR အသုံးပြုနည်းများ](/my/docs/ocr-workflows/) တွင် ကြည့်ပါ။

## မြန်မာစာ ပုံပျက်နေခြင်း

PDF ရဲ့ Text layer မှ ထုတ်ယူထားတဲ့ စာသားဆိုရင် Zawgyi ဖြစ်နေနိုင်ပါတယ်။ LEXO က Zawgyi မှ Unicode သို့ တိုက်ရိုက် မပြောင်းပေးပါဘူး။ Google Docs OCR ဖြင့် စာမျက်နှာပုံကို ပြန်ဖတ်ပြီး စံ Unicode စာသား ရယူနိုင်ပါတယ်။

## စာမျက်နှာ အချို့ မအောင်မြင်ခြင်း

ယာယီချို့ယွင်းမှုကြောင့် မအောင်မြင်တဲ့ စာမျက်နှာတွေကို LEXO က အလိုအလျောက် ပြန်ကြိုးစားပေးပါတယ်။ မအောင်မြင်သေးတဲ့ စာမျက်နှာတွေ ကျန်ရင် -

- အက်ပ်မှာ **Retry Failed Pages** ကို နှိပ်ပါ။ မအောင်မြင်တဲ့ စာမျက်နှာတွေကိုသာ ပြန်လုပ်ပေးပါတယ်။
- CLI တွင် မအောင်မြင်တဲ့ စာမျက်နှာ နံပါတ်များကို ပြပေးတဲ့အတွက် `--pages` ဖြင့် ပြန်လုပ်ပါ။

အင်တာနက် နှေးလွန်းခြင်း သို့မဟုတ် မတည်ငြိမ်ခြင်းကြောင့် ဖြစ်တတ်ပါတယ်။ `LEXO_CONCURRENCY` ကို လျှော့ချခြင်းဖြင့် အထောက်အကူ ဖြစ်နိုင်ပါတယ်။

## OCR စာသားတွင် ခေါင်းစီးနှင့် စာမျက်နှာနံပါတ်များ ပါနေခြင်း

OCR မလုပ်မီ ဖြတ်တောက်ပါ - **Edit** Tab ၏ Crop box သို့မဟုတ် `lexo pdf crop`။ [PDF ကိရိယာများ](/my/docs/pdf-tools/) တွင် ကြည့်ပါ။

## စာအုပ် စာမျက်နှာ နှစ်ခု ရောထွေးပြီး တစ်ခုတည်း ထွက်ခြင်း

စကင်ဖိုင်က စာမျက်နှာနှစ်ခုတွဲ ပုံ ဖြစ်ပါတယ်။ အရင် ခွဲပါ - PDF Tab ရှိ **Show split line** သို့မဟုတ် `lexo pdf split-spread`။

## App ထဲတွင် မြန်မာစာ လေးထောင့်ကွက်များ ပေါ်ခြင်း

LEXO မှာ Noto Sans Myanmar ဖောင့် ပါဝင်ပြီးသားဖြစ်လို့ အက်ပ်ထဲမှာ ပုံမှန်အားဖြင့် ဒီပြဿနာ မဖြစ်သင့်ပါဘူး။ ထုတ်ယူသိမ်းထားတဲ့ ဖိုင်ကို အခြားဆော့ဖ်ဝဲနဲ့ ဖွင့်မှ လေးထောင့်ကွက်တွေ ပေါ်ရင် အဲဒီဆော့ဖ်ဝဲမှာ မြန်မာ Unicode ဖောင့် မရှိလို့ ဖြစ်နိုင်ပါတယ်။ Noto Sans Myanmar သို့မဟုတ် Padauk လို ဖောင့်တစ်ခု ထည့်သွင်းပါ။

## ထည့်သွင်းပြီးနောက် `lexo` ကို ရှာမတွေ့ခြင်း

Tool တွေ ထည့်သွင်းထားတဲ့ Folder က PATH ထဲမှာ မပါသေးတာ ဖြစ်ပါတယ်။ uv သုံးထားရင် `uv tool update-shell` ကို လုပ်ဆောင်ပြီး terminal အသစ် ဖွင့်ပါ။ pipx သုံးထားရင် `pipx ensurepath` ကို လုပ်ဆောင်ပါ။

## အကူအညီ ထပ်လိုပါသလား

[GitHub](https://github.com/PhilixTheExplorer/lexo/issues) မှာ issue ဖွင့်ပြီး OS၊ Python ဗားရှင်း၊ LEXO ဗားရှင်း (`lexo --version`)၊ ထည့်သွင်းခဲ့တဲ့နည်းနဲ့ တွေ့ရတဲ့ပြဿနာကို ဖော်ပြပါ။ PDF နဲ့ ပုံတွေမှာ ကိုယ်ရေးအချက်အလက် ပါနေနိုင်လို့ ပူးတွဲမပေးမီ အရေးကြီးအချက်အလက်တွေကို ဖယ်ရှားပါ။
