## စာရွက်စာတမ်း ဖွင့်ခြင်း

- **Import PDF or Image** (`Ctrl+O`) - PDF သို့မဟုတ် ပုံ တစ်ပုံကို ဖွင့်ပါတယ်။
- **Select Image Set** (`Ctrl+Shift+O`) - ပုံအများအပြားကို တစ်ပုံလျှင် စာမျက်နှာတစ်ခုအဖြစ် ထည့်ပြီး စာရွက်စာတမ်းတစ်ခု ဖန်တီးပေးပါတယ်။ PNG၊ JPEG၊ TIFF နဲ့ BMP ဖိုင်တွေကို သုံးနိုင်ပါတယ်။
- **Batch OCR PDFs** (`Ctrl+Alt+O`) - PDF အများအပြားကို မဖွင့်ဘဲ OCR လုပ်ပါတယ်။ [Batch OCR](/my/docs/batch-ocr/) တွင် ကြည့်ပါ။

ဖိုင်ဖွင့်လိုက်တာနဲ့ ပြင်ဆင်ဖို့ ယာယီမိတ္တူတစ်ခု ဖန်တီးပေးပါတယ်။ ပြင်ဆင်မှုအားလုံးကို အဲဒီမိတ္တူမှာပဲ လုပ်ပါတယ်။ **File → Save** သို့မဟုတ် **Save As** နဲ့ မသိမ်းမချင်း မူရင်းဖိုင်ကို မပြောင်းလဲပါဘူး။

- **Pages Strip** (ဘယ်ဘက်) - စာမျက်နှာပုံငယ်တွေကို ပြထားတဲ့ စာရင်းဖြစ်ပါတယ်။ အပြာက Text layer ပါတဲ့ စာမျက်နှာ၊ အစိမ်းက OCR ပြီးဆုံး၊ အဝါက လုပ်ဆောင်ဆဲ၊ အနီက မအောင်မြင်တဲ့ အခြေအနေကို ပြပါတယ်။ `Ctrl` သို့မဟုတ် `Shift` ကို ဖိထားပြီး နှိပ်ရင် စာမျက်နှာအများအပြား ရွေးနိုင်ပါတယ်။
- **Preview** (အလယ်) - လက်ရှိစာမျက်နှာကို ပြပါတယ်။ Scroll လုပ်ရင် စာမျက်နှာ ပြောင်းနိုင်ပါတယ်။ `Ctrl` ကို ဖိပြီး scroll လုပ်ရင် ပုံကို ချဲ့၊ ချုံ့နိုင်ပြီး ဆွဲရွှေ့ကြည့်နိုင်ပါတယ်။ **Fit** ဖြင့် စာမျက်နှာအပြည့် ပြန်မြင်နိုင်ပါတယ်။
- **Text Pane** - လက်ရှိစာမျက်နှာရဲ့ စာသားကို ဖတ်ရှုပြင်ဆင်နိုင်တဲ့ အကွက်ဖြစ်ပါတယ်။ **Copy** (`Ctrl+Shift+C`) ဖြင့် ကူးယူနိုင်ပါတယ်။
- **Tune Panel** (ညာဘက်) - အောက်တွင် ရှင်းပြထားတဲ့ Tab လေးခု။

ဘေး Panel နှစ်ခုလုံးကို အရွယ်အစား ပြောင်းနိုင်၊ ပိတ်နိုင်ပြီး **View** Menu မှ ပြန်ဖွင့်နိုင်ပါတယ်။

## Run Tab

Mode တစ်ခု ရွေးပါ -

- **Text layer** - PDF ထဲမှာ ပါပြီးသား စာသားကို တိုက်ရိုက် ကူးယူပေးပါတယ်။ ချက်ချင်း ရရှိပြီး အင်တာနက်နဲ့ အကောင့် မလိုပါဘူး။
- **Google Docs OCR** - စကင်ဖတ်ထားတဲ့ စာမျက်နှာနှင့် ပုံများကို မိမိ Google အကောင့်မှတစ်ဆင့် ဖတ်ပါတယ်။ [တစ်ကြိမ်သာ လုပ်ရတဲ့ ပြင်ဆင်မှု](/my/docs/google-cloud-setup/) လိုပါတယ်။

ပြီးရင် **Run** (`Ctrl+R`) ကို နှိပ်ပါ။ **Cancel** (`Esc`) ဖြင့် ရပ်နိုင်ပါတယ်။ Progress bar မှာ ပြီးဆုံးတဲ့ စာမျက်နှာအရေအတွက်ကို ပြပေးပြီး စာမျက်နှာတစ်ခု ပြီးတိုင်း ရလာတဲ့စာသားကို ချက်ချင်း ဖတ်နိုင်ပါတယ်။

အလိုအလျောက် ပြန်ကြိုးစားပြီးနောက် မအောင်မြင်တဲ့ စာမျက်နှာတွေ ကျန်ရင် **Retry Failed Pages** (`Ctrl+Shift+R`) ဖြင့် အဲဒီစာမျက်နှာတွေကိုသာ ပြန်လုပ်နိုင်ပါတယ်။

အကောင့်မဝင်ထားဘဲ OCR စတင်ပါက LEXO က အကောင့်ဝင်ဖို့ လမ်းညွှန်ပြီး လုပ်ဆောင်မှုကို ပြန်စပေးပါတယ်။

**Export as** တွင် File format (Plain text၊ Markdown သို့မဟုတ် JSONL) ကို ရွေးပြီး **Export** (`Ctrl+E`) ဖြင့် ဖိုင်သိမ်းပါ။ [သိမ်းဆည်းနိုင်တဲ့ File format တွေ](/my/docs/export-formats/) တွင် ကြည့်ပါ။

## Edit Tab - Rotate နှင့် Crop

ဒီ tab မှာ ပြင်ဆင်တဲ့အခါ ဘယ်စာမျက်နှာတွေကို သက်ရောက်စေမလဲဆိုတာ **Apply to** မှာ ရွေးပါ။ **This page** က လက်ရှိစာမျက်နှာ၊ **All pages** က စာမျက်နှာအားလုံး၊ **Selected pages** က ရွေးထားတဲ့ စာမျက်နှာတွေ ဖြစ်ပါတယ်။

- **Rotate** - ဘယ် ၉၀° သို့မဟုတ် ညာ ၉၀°။
- **Crop** - Edit tab သို့ ပြောင်းရင် စာမျက်နှာပုံပေါ်မှာ Crop box ပေါ်လာပါမယ်။ ခေါင်းစီး၊ စာမျက်နှာနံပါတ်နဲ့ ဘေးလွတ်နေရာတွေကို ဖယ်ဖို့ ဘောင်အစွန်းတွေကို ဆွဲရွှေ့ပါ သို့မဟုတ် ဘောင်အသစ် ဆွဲပါ။ ဖြတ်တောက်မယ့် ပမာဏကို ရာခိုင်နှုန်းဖြင့်လည်း ထည့်နိုင်ပါတယ်။ ပြီးရင် **Apply crop** ကို နှိပ်ပါ။

ဖြတ်တောက်ပြီးသား စာမျက်နှာကို ထပ်ဖြတ်ရင် မူရင်းဘောင်ကနေ ပြန်စတာ မဟုတ်ပါဘူး။ လက်ရှိဖြတ်တောက်ထားတဲ့ ဘောင်အတွင်းကနေ ထပ်ဖြတ်ပေးပါတယ်။

## Pages Tab

- **Run Pages** - လုပ်ဆောင်မယ့် စာမျက်နှာများကို ကန့်သတ်ပါတယ်။ `all`၊ `odd`၊ `even` သို့မဟုတ် `1-3,7,10-` ကဲ့သို့ ရိုက်ပါ သို့မဟုတ် အမြန်ခလုတ်များကို သုံးပါ။ ရိုက်နေစဉ် ကိုက်ညီသော စာမျက်နှာပုံငယ်များကို ရွေးပေးပါတယ်။
- **Extract selected to new file…** (`Ctrl+Shift+E`) - ရွေးထားတဲ့ စာမျက်နှာများကို PDF အသစ်အဖြစ် သိမ်းပါတယ်။
- **Remove selected pages** (`Delete`) - ပြင်ဆင်ဖို့ ဖန်တီးထားတဲ့ မိတ္တူထဲက ရွေးထားတဲ့ စာမျက်နှာတွေကို ဖယ်ရှားပါတယ်။

**Move Up** နှင့် **Move Down** (`Ctrl+Shift+↑` / `Ctrl+Shift+↓`) သို့မဟုတ် စာမျက်နှာပုံငယ် ပေါ်တွင် Right-click နှိပ်၍ စာမျက်နှာ အစီအစဉ် ပြောင်းနိုင်ပါတယ်။ Right-click Menu တွင် Rotate၊ Extract နှင့် Remove လည်း ပါတယ်။

## PDF Tab - Spread၊ ဖိုင်ခွဲခြင်း၊ ပေါင်းထည့်ခြင်း

- **Show split line** - Preview ပေါ်မှာ ဒေါင်လိုက်မျဉ်း တစ်ကြောင်း ပေါ်လာပါမယ်။ Two-up စကင်ဖိုင်၏ အလယ်ကြောင်းသို့ ဆွဲရွှေ့ပြီး **Split two-up at line** နှိပ်ပါ။ စာမျက်နှာတစ်ခုစီ နှစ်ခုဖြစ်သွားပြီး ဘယ်ခြမ်း အရင်လာပါမယ်။
- **Split into files…** - PDF ကို N မျက်နှာစီပါတဲ့ ဖိုင်များအဖြစ် ခွဲပါတယ်။
- **Append PDF(s)…** - အခြား PDF များကို နောက်ဆုံးတွင် ပေါင်းထည့်ပါတယ်။

ပြင်ဆင်မှုတွေကို နောက်ကွယ်မှာ လုပ်ဆောင်တာကြောင့် စာမျက်နှာများတဲ့ ဖိုင်တွေကို ကိုင်တွယ်နေချိန်မှာလည်း အက်ပ်ကို ဆက်လက် အသုံးပြုနိုင်ပါတယ်။

## Keyboard shortcuts

| လုပ်ဆောင်ချက် | Shortcut |
|---|---|
| PDF သို့မဟုတ် ပုံ ဖွင့်ရန် | `Ctrl+O` |
| ပုံအစု ဖွင့်ရန် | `Ctrl+Shift+O` |
| Batch OCR PDFs | `Ctrl+Alt+O` |
| Save / Save As | `Ctrl+S` / `Ctrl+Shift+S` |
| စာသားကို ဖိုင်အဖြစ် သိမ်းရန် | `Ctrl+E` |
| စာရွက်စာတမ်း ပိတ်ရန် | `Ctrl+W` |
| Run / Cancel | `Ctrl+R` / `Esc` |
| မအောင်မြင်တဲ့ စာမျက်နှာများ ပြန်လုပ် | `Ctrl+Shift+R` |
| စာမျက်နှာစာသား ကူးယူရန် | `Ctrl+Shift+C` |
| စာမျက်နှာ အပေါ် / အောက် ရွှေ့ရန် | `Ctrl+Shift+↑` / `Ctrl+Shift+↓` |
| ရွေးထားတဲ့ စာမျက်နှာများ ထုတ်ယူရန် | `Ctrl+Shift+E` |
| ရွေးထားတဲ့ စာမျက်နှာများ ဖယ်ရှားရန် | `Delete` |
| About Lexo | `F1` |

macOS တွင် Qt က ဒီ Shortcut များရှိ `Ctrl` ကို `⌘ Command` အဖြစ် ပြောင်းပေးပါတယ်။

## အခြား

- **Account** Menu တွင် အကောင့်ဝင်ထားခြင်း ရှိမရှိကို ပြပြီး **Sign in with Google**၊ **Sign out** နှင့် **Copy Data Folder Path** တို့ ပါတယ်။
- **Help → Clean Up Temporary Files…** - အရင်အသုံးပြုခဲ့စဉ်က ကျန်တဲ့ ယာယီမိတ္တူတွေကို ဖယ်ရှားပါတယ်။
- **Help → Check for Updates…** - မိမိသုံးနေတဲ့ ဗားရှင်းကို PyPI နှင့် နှိုင်းယှဉ်ပါတယ်။
