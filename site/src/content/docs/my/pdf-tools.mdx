LEXO ရဲ့ PDF ကိရိယာတွေက မိမိကွန်ပျူတာမှာပဲ လုပ်ဆောင်ပါတယ်။ Google အကောင့်နဲ့ အင်တာနက် မလိုပါဘူး။ OCR မလုပ်မီ စာမျက်နှာတွေကို ပြင်ဆင်ဖို့ သုံးနိုင်သလို PDF ပြင်ဆင်ရေးအတွက်လည်း သီးခြား သုံးနိုင်ပါတယ်။

ကိရိယာအားလုံးကို အက်ပ်ရဲ့ **Edit**၊ **Pages** နဲ့ **PDF** tab တွေမှာ သုံးနိုင်သလို `lexo pdf` command ဖြင့်လည်း သုံးနိုင်ပါတယ်။

## စာမျက်နှာ အပိုင်းအခြားများ

`--pages` (`-p`) ပါတဲ့ command တွေမှာ အောက်ပါအတိုင်း သတ်မှတ်နိုင်ပါတယ် -

- `all`၊ `odd` သို့မဟုတ် `even`
- စာမျက်နှာ တစ်ခုချင်းနှင့် အပိုင်းအခြားများကို ကော်မာခြား၍ - `1-3,7,10-`။ `10-` ကဲ့သို့ အဆုံးမပါတဲ့ အပိုင်းအခြားက နောက်ဆုံး စာမျက်နှာအထိ ဖြစ်ပါတယ်။

စာမျက်နှာ နံပါတ်များကို ၁ မှ စ၍ ရေတွက်ပါတယ်။

## PDF ကို စစ်ဆေးခြင်း

```bash
lexo pdf info book.pdf
```

စာမျက်နှာ အရေအတွက်၊ Text layer ပါမပါနှင့် ပထမ စာမျက်နှာ၏ အရွယ်အစားကို ပြပါတယ်။

## စာမျက်နှာ အပိုင်းအခြား ထုတ်ယူခြင်း

```bash
lexo pdf extract book.pdf --pages "1-3,7,10-" -o subset.pdf
```

အက်ပ်မှာ စာမျက်နှာပုံငယ်တွေကို ရွေးပြီး **Extract selected to new file…** ကို နှိပ်ပါ။

## ဖိုင်များအဖြစ် ခွဲခြင်း

စာမျက်နှာ အရေအတွက်အလိုက် -

```bash
lexo pdf split book.pdf --every 10
```

သို့မဟုတ် သတ်မှတ်ထားတဲ့ စာမျက်နှာများမှ ဖိုင်အသစ် စတင်စေရန် -

```bash
lexo pdf split book.pdf --at 4,7
```

`--out-dir` မပေးရင် မူရင်းဖိုင်နဲ့ Folder တူထဲမှာ ထုတ်ပေးပါတယ်။

## ဘေးလွတ်နေရာ ဖြတ်တောက်ခြင်း

အစွန်းတစ်ခုစီမှ ဖြတ်မည့် ရာခိုင်နှုန်း -

```bash
lexo pdf crop book.pdf --top 8 --bottom 8 -o trimmed.pdf
lexo pdf crop book.pdf --left 5 --right 5 --pages odd -o trimmed.pdf
```

အက်ပ်ရဲ့ **Edit** tab မှာ Crop box ကို ဆွဲရွှေ့ပြီး ပုံကိုကြည့်ကာ ပြင်ဆင်နိုင်ပါတယ်။ လက်ရှိစာမျက်နှာ၊ စာမျက်နှာအားလုံး သို့မဟုတ် ရွေးထားတဲ့ စာမျက်နှာတွေကို သက်ရောက်စေနိုင်ပါတယ်။ စာမျက်နှာကို လှည့်ထားရင်လည်း လက်ရှိမြင်ရတဲ့ အနားသတ်အတိုင်း ဖြတ်ပေးပါတယ်။

## လှည့်ခြင်း

```bash
lexo pdf rotate book.pdf --degrees 90 -o rotated.pdf
lexo pdf rotate book.pdf -d 180 --pages even -o rotated.pdf
```

`--degrees` မှာ ၉၀၊ ၁၈၀၊ ၂၇၀ စတဲ့ ၉၀ နဲ့ စားလို့ပြတ်တဲ့ တန်ဖိုးတွေကို ပေးနိုင်ပါတယ်။

## ပေါင်းခြင်း

```bash
lexo pdf merge front.pdf body.pdf back.pdf -o book.pdf
```

ပေးထားတဲ့ အစဉ်အတိုင်း ပေါင်းပါတယ်။ App တွင် PDF Tab ရှိ **Append PDF(s)…** ဖြင့် ဖွင့်ထားတဲ့ ဖိုင်၏ နောက်ဆုံးတွင် ပေါင်းထည့်နိုင်ပါတယ်။

## စာမျက်နှာနှစ်ခုတွဲ ပုံ ခွဲခြင်း

ဖွင့်ထားတဲ့ စာအုပ်ကို စကင်ဖတ်ထားရင် ပုံတစ်ပုံတွင် စာမျက်နှာ နှစ်ခု ပါတတ်ပါတယ်။ ဘယ်ခြမ်း၊ ညာခြမ်း ခွဲရန် -

```bash
lexo pdf split-spread scans.pdf -o pages.pdf
```

အလယ်ကြောင်းက အလယ်တည့်တည့် မဟုတ်ရင် `--ratio` ဖြင့် ဖြတ်မည့်နေရာကို `0.05` မှ `0.95` အတွင်း ရွှေ့နိုင်ပါတယ် (မူလ `0.5`) -

```bash
lexo pdf split-spread scans.pdf --ratio 0.52 -o pages.pdf
```

App တွင် **Show split line** ဖြင့် မျဉ်းကို အလယ်ကြောင်းပေါ် ဆွဲတင်ပြီး **Split two-up at line** နှိပ်ပါ။

ခွဲတဲ့အခါ စာမျက်နှာကို လှည့်ထားတဲ့အနေအထားနဲ့ လက်ရှိ Crop box ကို ထည့်တွက်ပေးပါတယ်။ ဒါကြောင့် ခွဲပြီးသား PDF ကို ထပ်ခွဲရင် တစ်ခြမ်းတည်းကို ထပ်ယူမိတာမျိုး မဖြစ်ပါဘူး။
