"ဒီ PDF ထဲက စာသားကို ထုတ်ပေးပါ" ဆိုရင် အလုပ်တစ်မျိုးတည်းလို့ ထင်ရပေမယ့် ဖိုင်ပေါ်မူတည်ပြီး နည်းလမ်းနှစ်မျိုး ရှိပါတယ်။ မှန်ကန်တဲ့ နည်းကို ရွေးခြင်းဖြင့် နာရီပေါင်းများစွာ သက်သာစေပါတယ်။

## PDF နှစ်မျိုး

**စာသားပါ PDF (Digital PDF)** ဆိုတာ Word၊ LibreOffice၊ InDesign ဒါမှမဟုတ် ဝဘ်စာမျက်နှာကနေ ထုတ်ထားတဲ့ PDF မျိုးပါ။ Text layer ပါပြီးသားဖြစ်လို့ စာသားကို ရွေး၊ ရှာ၊ ကူးယူနိုင်ပါတယ်။

**စကင် PDF** ဆိုတာ စကင်နာ ဒါမှမဟုတ် ဖုန်းကင်မရာနဲ့ ရယူထားတဲ့ စာမျက်နှာပုံတွေကို စုထားတာ ဖြစ်ပါတယ်။ စာမျက်နှာတစ်ခုချင်းမှာ ကူးယူနိုင်တဲ့ Text layer မပါဘဲ စာသားပုံရိပ်ပဲ ပါဝင်ပါတယ်။

လက်တွေ့အသုံးပြုနေတဲ့ ဖိုင်တွေမှာ စာသားနဲ့ စကင်ဖတ်ထားတဲ့ စာမျက်နှာတွေ ရောနှောပါဝင်နေလေ့ရှိပါတယ်။ ဥပမာ၊ လက်မှတ်ထိုးထားတဲ့ စာမျက်နှာတွေကို စကင်ဖတ်ပြီး ထည့်ထားတဲ့ အစီရင်ခံစာတွေ၊ စာမျက်နှာအချို့ကို ပြန်လည်စကင်ဖတ်ထားတဲ့ စာအုပ်တွေ ဖြစ်ပါတယ်။

## PDF အမျိုးအစား ခွဲခြားနည်း

PDF ဖတ်တဲ့ ဆော့ဖ်ဝဲမှာ စာကြောင်းတစ်ကြောင်းကို ရွေးကြည့်ပါ။ စကားလုံးတစ်လုံးချင်းကို ရွေးလို့ရရင် Text layer ပါပါတယ်။ စာမျက်နှာပေါ်မှာ လေးထောင့်ဘောင် ဆွဲလို့ရရုံပဲဆိုရင် ပုံအဖြစ် သိမ်းထားတာ ဖြစ်ပါတယ်။

LEXO ဖြင့်လည်း စစ်ဆေးနိုင်ပါတယ် -

```bash
lexo pdf info document.pdf
```

စာမျက်နှာ အရေအတွက်နှင့် Text layer ပါမပါကို ပြပါမယ်။

## စာသားပါ PDF - OCR မလုပ်ဘဲ ထုတ်ယူပါ

Text layer ပါပြီးသားဆိုရင် ပုံကနေ ပြန်ဖတ်တာထက် တိုက်ရိုက် ကူးယူတာက ပိုမြန်ပြီး ပိုတိကျပါတယ်။ အင်တာနက်နဲ့ အကောင့် မလိုသလို ပုံကိုဖတ်ရာကနေ ဖြစ်လာနိုင်တဲ့ အမှားတွေလည်း မရှိပါဘူး။

```bash
lexo extract document.pdf -o document.txt
```

Desktop app မှာ **Text layer** ကို ရွေးပြီး **Run** နှိပ်ပါ။

မြန်မာ PDF တွေမှာ သတိပြုစရာတစ်ခု ရှိပါတယ်။ ထုတ်ယူထားတဲ့ စာသားက လက်တင်စာလုံးတွေ ဖြစ်နေရင် Win Innwa လို ဖောင့်ဟောင်း သုံးထားတာ ဖြစ်ပါတယ်။ Text layer ရှိပေမယ့် Unicode မဟုတ်လို့ ဒီလိုဖိုင်တွေအတွက် OCR ကို သုံးပါ။ [အကြောင်းရင်းကို အသေးစိတ် ဖတ်ရှုနိုင်ပါတယ်](/my/blog/win-innwa-pdf-to-unicode/)။

## စကင် PDF - OCR လုပ်ပါ

စာမျက်နှာပုံကနေ စာသားရဖို့ OCR လိုပါတယ်။ LEXO က မြန်မာစာကို မူလဘာသာစကားအဖြစ် သတ်မှတ်ထားပြီး မိမိ Google အကောင့်မှတစ်ဆင့် Google Docs OCR ကို သုံးပါတယ် -

```bash
lexo ocr scan.pdf -o scan.txt
```

[တစ်ကြိမ်သာ လုပ်ရတဲ့ Google Cloud ပြင်ဆင်မှု](/my/docs/google-cloud-setup/) လိုပါတယ်။ စာအုပ်တစ်အုပ်လုံးကို မလုပ်မီ ခေါင်းစီးများကို ဖြတ်တောက်ပြီး စာမျက်နှာနှစ်ခုတွဲ ပုံများကို ခွဲပါ။ [အဆင့်ဆင့် လမ်းညွှန်](/my/blog/scanned-burmese-pdf-to-unicode-text/) တွင် နှစ်ခုလုံး ပါတယ်။

## နှစ်မျိုးရောနေတဲ့ PDF ကို ကိုင်တွယ်နည်း

`lexo ocr` က စာမျက်နှာတစ်ခုချင်းကို စစ်ဆေးပါတယ်။ အသုံးပြုနိုင်တဲ့ Text layer ပါရင် တိုက်ရိုက်ထုတ်ယူပြီး မပါရင် ပုံအဖြစ် ပြောင်းကာ OCR လုပ်ပါတယ်။ ဒါကြောင့် command တစ်ကြောင်းတည်းနဲ့ ပါပြီးသားစာသားကို မူရင်းအတိုင်း ရယူနိုင်ပြီး လိုအပ်တဲ့ စာမျက်နှာတွေကိုသာ OCR လုပ်နိုင်ပါတယ် -

```bash
lexo ocr mixed.pdf -o mixed.txt
```

Text layer ပါပေမယ့် အမှားများနေရင် စာမျက်နှာအားလုံးကို OCR ပြန်လုပ်နိုင်ပါတယ်။ စကင်နာအချို့က မမှန်ကန်တဲ့ OCR Text layer ကို နောက်ကွယ်မှာ ထည့်ထားတတ်ပါတယ် -

```bash
lexo ocr mixed.pdf --force-ocr -o mixed.txt
```

## အမြန် ဆုံးဖြတ်ရန် ဇယား

| မြင်ရတဲ့အခြေအနေ | သုံးရမယ့် command |
|---|---|
| စာသားကို စကားလုံးအလိုက် ရွေးနိုင်ပြီး ပြန်ထည့်လိုက်ရင် မှန်တယ် |  `lexo extract` |
| စာသား လုံးဝ ရွေး၍မရ | `lexo ocr` |
| မြန်မာစာလို့ မြင်ရပေမယ့် ပြန်ထည့်လိုက်ရင် အင်္ဂလိပ်စာလုံးများ | `lexo ocr --force-ocr` |
| ပြန်ထည့်လိုက်ရင် မြန်မာစာ ပုံပျက်နေတယ် |  `lexo ocr --force-ocr` (Zawgyi ဖြစ်နိုင်) |
| စာမျက်နှာ အချို့ ရွေးနိုင်ပြီး အချို့ မရွေးနိုင် | `lexo ocr` |
