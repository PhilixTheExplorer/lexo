စကင်ဖတ်ထားတဲ့ PDF ဆိုတာ စာမျက်နှာပုံတွေကို စုထားတဲ့ဖိုင် ဖြစ်ပါတယ်။ စာသားကို မြင်ရပေမယ့် ကွန်ပျူတာက ပုံအဖြစ်ပဲ သိမ်းထားတာကြောင့် စာသားရှာဖွေတာ၊ ကူးယူတာနဲ့ စာလုံးပေါင်းစစ်တာတွေ လုပ်လို့ မရပါဘူး။ ပုံထဲက စာလုံးတွေကို ဖတ်ပြီး စာသားအဖြစ် ပြောင်းပေးတဲ့ နည်းပညာကို OCR (Optical Character Recognition) လို့ ခေါ်ပါတယ်။

ဒီလမ်းညွှန်မှာ အခမဲ့ မြန်မာ OCR အက်ပ်ဖြစ်တဲ့ LEXO ကို သုံးပြီး စကင်ဖိုင်ကနေ ပြင်ဆင်ထုတ်ဝေနိုင်တဲ့ Unicode စာသားရရှိတဲ့အထိ အဆင့်ဆင့် ရှင်းပြထားပါတယ်။

## မစတင်မီ

လိုအပ်တာတွေ -

- **LEXO** - `uv tool install lexo` (သို့မဟုတ် `pipx install lexo`) ဖြင့် ထည့်သွင်းပါ။ [ထည့်သွင်းခြင်း](/my/docs/installation/) တွင် ကြည့်ပါ။
- **Google အကောင့်** - LEXO က ပုံနှိပ်မြန်မာစာကို ဖတ်နိုင်တဲ့ အခမဲ့ Google Docs OCR ကို သုံးပါတယ်။
- **Google Cloud ကြိုတင်ပြင်ဆင်မှု** - မိမိအကောင့်ကနေ Google Docs OCR သုံးခွင့်ရဖို့ တစ်ကြိမ် ပြင်ဆင်ရပါတယ်။ [ပြင်ဆင်နည်း လမ်းညွှန်](/my/docs/google-cloud-setup/) မှာ အဆင့်ခြောက်ဆင့်နဲ့ ရှင်းပြထားပါတယ်။

ထို့နောက် အကောင့်ဝင်ပါ -

```bash
lexo login
```

## အဆင့် ၁ - စကင်ဖိုင် ဟုတ်မဟုတ် စစ်ဆေးပါ

စကင်ဖိုင်လို့ ထင်ရတဲ့ PDF အချို့မှာ Text layer ပါပြီးသား ဖြစ်နေနိုင်ပါတယ်။ ပါနေရင် OCR မလုပ်ဘဲ တိုက်ရိုက် ထုတ်ယူနိုင်တာကြောင့် အရင်စမ်းကြည့်ပါ -

```bash
lexo extract book.pdf -o book.txt
```

LEXO က "looks scanned" လို့ ပြရင် သို့မဟုတ် ဘာမှ မထွက်ရင် ဆက်လုပ်ပါ။ စာမျက်နှာက မြန်မာစာ ဖြစ်ပေမယ့် အင်္ဂလိပ်စာလုံးများ ထွက်လာရင် ဖောင့်ဟောင်း ဖြစ်ပါတယ် - [Win Innwa PDF မှ Unicode သို့](/my/blog/win-innwa-pdf-to-unicode/) ကို ဖတ်ပါ။

## အဆင့် ၂ - Desktop app မှာ PDF ကို ဖွင့်ပါ

```bash
lexo gui
```

**Import PDF or Image** ကို နှိပ်ပြီး ဖိုင်ကို ရွေးပါ။ LEXO က ပြင်ဆင်ဖို့ ဖန်တီးထားတဲ့ မိတ္တူတစ်ခု ပြုလုပ်တဲ့အတွက် Save မလုပ်မချင်း မူရင်းကို မပြောင်းလဲပါဘူး။

## အဆင့် ၃ - စာမျက်နှာနှစ်ခုတွဲ ပုံများကို ခွဲပါ

စကင်ပုံတစ်ပုံတွင် စာအုပ်စာမျက်နှာ နှစ်ခု ယှဉ်လျက် ပါနေရင် OCR မလုပ်မီ ခွဲပါ။ မခွဲရင် ဘယ်ညာ စာမျက်နှာများမှ စာကြောင်းများ ရောထွေးသွားနိုင်ပါတယ်။

Tune Panel ရှိ **PDF** Tab ကို ဖွင့်ပြီး **Show split line** နှိပ်ပါ၊ မျဉ်းကို အလယ်ကြောင်းပေါ် ဆွဲတင်ပါ၊ **Split two-up at line** နှိပ်ပါ။

## အဆင့် ၄ - ခေါင်းစီးနှင့် စာမျက်နှာနံပါတ်များကို ဖြတ်တောက်ပါ

စာမျက်နှာတိုင်း၏ အပေါ်ရှိ စာအုပ်အမည်နှင့် အောက်ရှိ စာမျက်နှာနံပါတ်များကို မဖယ်ရှားရင် စာသားထဲ ပါလာပါမယ်။ **Edit** Tab သို့ ပြောင်းလိုက်ရင် စာမျက်နှာပေါ်တွင် Crop box ပေါ်လာပါမယ်။ အစွန်းများကို စာသားဘောင်အထိ ဆွဲပြီး **Apply to** ကို **All pages** ထားကာ **Apply crop** နှိပ်ပါ။

## အဆင့် ၅ - Google Docs OCR စတင်ပါ

**Run** Tab သို့ ပြန်သွားပြီး **Google Docs OCR** ကို ရွေးကာ **Run** နှိပ်ပါ။ ဘာသာစကား သတ်မှတ်ချက်ရဲ့ Default value မှာ မြန်မာစာ ဖြစ်ပါတယ်။

LEXO က စာမျက်နှာတစ်ခုချင်းကို ပုံအဖြစ် ပြောင်းပြီး မိမိ Google Drive ဆီ တင်ပို့ပါတယ်။ Google Docs OCR နဲ့ ဖတ်ပြီး စာသားကို ပြန်ယူကာ ယာယီဖိုင်ကို ဖျက်ပါတယ်။ ရလာတဲ့စာသားတွေကို Text pane မှာ တစ်မျက်နှာချင်း ချက်ချင်း ပြပေးပါတယ်။ စာအုပ်ရှည်ရင် အချိန်ပိုယူပါမယ်။ ကြာချိန်က အင်တာနက်နဲ့ Google ရဲ့ တုံ့ပြန်ချိန်ပေါ် မူတည်ပါတယ်။

အင်တာနက် ပြတ်တောက်မှုကြောင့် စာမျက်နှာ မအောင်မြင်ပါက LEXO က အလိုအလျောက် ထပ်မံကြိုးစားပါတယ်။ နောက်ဆုံးတွင် မအောင်မြင်သေးတာတွေကို **Retry Failed Pages** ဖြင့် သီးခြား ပြန်လုပ်နိုင်ပါတယ်။

## အဆင့် ၆ - ယှဉ်တွဲ စစ်ဆေးပါ

<Shot src={result} alt="စကင်ဖတ်ထားတဲ့ မြန်မာစာမျက်နှာနှင့် ရလာတဲ့ Unicode စာသားကို LEXO မှာ ယှဉ်တွဲပြထားပုံ။" caption="စာမျက်နှာပုံနဲ့ စာသားကို ယှဉ်စစ်ပြီး အမှားတွေကို တိုက်ရိုက် ပြင်ဆင်နိုင်ပါတယ်။" />

OCR ရလဒ်မှာ အမှားတွေ ပါနေနိုင်တာကြောင့် မူရင်းစာမျက်နှာပုံနဲ့ တစ်မျက်နှာချင်း ယှဉ်စစ်ပါ။ ဖတ်ရခက်တဲ့နေရာတွေကို `Ctrl` ဖိပြီး mouse wheel လှိမ့်ကာ ချဲ့ကြည့်နိုင်ပါတယ်။ အထူးသဖြင့် အောက်ပါတို့ကို စစ်ဆေးပါ -

- စာလုံးသေး သို့မဟုတ် မှိန်နေသော ပုံနှိပ်စာရှိ ပါဌ်ဆင့်နှင့် ယပင့်၊ ရရစ် စသည်တို့
- ဂဏန်းများဘေးရှိ ပုဒ်ဖြတ် (`၊` နှင့် `။`)
- စာမျက်နှာ ကူးသွားသော စာကြောင်းများ

## အဆင့် ၇ - ဖိုင်အဖြစ် သိမ်းပါ

**Export as** တွင် File format ရွေးပြီး **Export** နှိပ်ပါ -

- ဖတ်ရှု ပြင်ဆင်ရန် **Plain Text**
- ကိုးကားချက်နှင့် EPUB အလုပ်အတွက် စာမျက်နှာတိုင်း ခေါင်းစဉ်ပါတဲ့ **Markdown**
- Dataset အတွက် တစ်မျက်နှာလျှင် မှတ်တမ်းတစ်ခုပါတဲ့ **JSONL**

စာသားကို Unicode NFC စံပုံစံနဲ့ ညီအောင် ပြင်ဆင်ပြီး မြန်မာ Zero-width Space များကို ထိန်းထားပါတယ်။ [File format တွေ အကြောင်း](/my/docs/export-formats/)။

## CLI ဖြင့် လုပ်ခြင်း

အထက်ပါ အဆင့်တိုင်းကို CLI ဖြင့်လည်း လုပ်နိုင်ပါတယ် -

```bash
lexo pdf split-spread scan.pdf -o pages.pdf
lexo pdf crop pages.pdf --top 7 --bottom 9 -o cropped.pdf
lexo ocr cropped.pdf --lang my -o book.txt
```

PDF Folder တစ်ခုလုံးအတွက် [Batch OCR](/my/docs/batch-ocr/) ကို သုံးပါ -

```bash
lexo ocr-batch ./scans --out-dir ./txt
```

## ကိုယ်ရေးအချက်အလက် လုံခြုံမှု မှတ်ချက်

OCR လုပ်မယ့် စာမျက်နှာပုံတွေကို မိမိ Google Drive သို့ ပို့ဖတ်ပြီး ယာယီဖိုင်ကို ပြန်ဖျက်ပါတယ်။ ဖိုင်ဖွင့်တာ၊ စာမျက်နှာဖြတ်တောက်တာ၊ ခွဲတာ၊ စာသားစစ်ဆေးတာနဲ့ ဖိုင်သိမ်းတာတွေကိုတော့ မိမိကွန်ပျူတာမှာပဲ လုပ်ပါတယ်။ Google သို့ တင်ပို့ခွင့်ရှိတဲ့ စာရွက်စာတမ်းတွေကိုသာ OCR လုပ်ပါ။ [ကိုယ်ရေးအချက်အလက် လုံခြုံမှုနှင့် အကောင့်ဝင်ခြင်း](/my/docs/privacy/) မှာ အသေးစိတ် ဖတ်နိုင်ပါတယ်။
