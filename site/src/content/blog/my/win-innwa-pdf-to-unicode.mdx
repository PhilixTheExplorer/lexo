မြန်မာ PDF ဟောင်း တစ်ခုကို ဖွင့်ကြည့်ရင် မျက်နှာပြင်ပေါ်မှာ ကောင်းကောင်း ဖတ်လို့ရပါတယ်။ စာပိုဒ်တစ်ခုကို ရွေးပြီး Document တစ်ခုထဲ ကူးထည့်လိုက်တဲ့အခါ `armfaumif;edkuf` ကဲ့သို့ စာလုံးများ ထွက်လာပါတယ်။ စာသား ရှိပေမယ့် မြန်မာစာ မဟုတ်ပါဘူး။

ဖိုင်ပျက်နေတာ၊ ဆော့ဖ်ဝဲချို့ယွင်းနေတာ မဟုတ်ပါဘူး။ အရင်က မြန်မာစာရွက်စာတမ်း အများအပြားကို ဒီနည်းနဲ့ ရေးသားခဲ့ကြလို့ ဖြစ်ပါတယ်။

## ဘာကြောင့် ဖြစ်ရသလဲ

မြန်မာ Unicode မတွင်ကျယ်မီက **Win Innwa** နဲ့ **Win Myanmar** လို ဖောင့်တွေကို သုံးပြီး မြန်မာစာ ရိုက်ခဲ့ကြပါတယ်။ ဒီဖောင့်တွေက မြန်မာ code point တွေအစား ပုံမှန်ကီးဘုတ်က စာလုံးတွေ (`a`၊ `r`၊ `m`၊ `;`) ကို သုံးထားပြီး အဲဒီစာလုံးတွေကို မြန်မာစာပုံစံနဲ့ ပြသထားတာ ဖြစ်ပါတယ်။

ထို့ကြောင့် `m` ခလုတ်ကို နှိပ်ရင် ဖိုင်ထဲတွင် `m` စာလုံးကို သိမ်းပြီး ဖောင့်က မြန်မာ စာလုံးကို ဆွဲပြပါတယ်။ အဲဒီဖောင့်ရှိတဲ့ ကွန်ပျူတာမျက်နှာပြင်ပေါ်မှာ မှန်ကန်စွာ မြင်ရပေမယ့် အောက်ခံမှာ ASCII သာ ဖြစ်ပါတယ်။

ဒီလိုစာရွက်စာတမ်းကနေ ထုတ်ထားတဲ့ PDF မှာလည်း Text layer က ASCII ပဲ ဖြစ်ပါတယ်။ PDF ထဲ ထည့်ထားတဲ့ ဖောင့်က မြန်မာစာအဖြစ် ပြပေးထားတာ ဖြစ်ပါတယ်။ စာသားကူးယူတာ၊ ထုတ်ယူတာ၊ ရှာဖွေတာ ဒါမှမဟုတ် screen reader နဲ့ ဖတ်တာတွေ လုပ်ရင် ASCII စာလုံးတွေကိုသာ ရပါမယ်။

## သိရှိနိုင်ပုံ

စာသားကို ထုတ်ယူကြည့်ပါ။ LEXO တွင် PDF ကို **Text layer** Mode ဖြင့် ဖွင့်၍ စတင်ပါ သို့မဟုတ် Command Line မှ -

```bash
lexo extract document.pdf
```

စာမျက်နှာတွင် မြန်မာစာ ပေါ်နေပြီး Text pane မှာ လက်တင်စာလုံးနှင့် ပုဒ်ဖြတ်သင်္ကေတများ ပေါ်ရင် ဖောင့်ဟောင်း PDF ဖြစ်ပါတယ်။

ပုံစံမတူပေမယ့် OCR ဖြင့် ဖြေရှင်းနိုင်တဲ့ အခြားအခြေအနေ နှစ်မျိုးလည်း ရှိပါတယ် -

- **Private Use Area glyph များ** - PDF အချို့မှာ မြန်မာစာအစား ဖောင့်တစ်မျိုးတည်းအတွက် သတ်မှတ်ထားတဲ့ glyph ID တွေကို သိမ်းထားပါတယ်။ ဒီလို Text layer ကို အသုံးပြုမရကြောင်း စစ်တွေ့ရင် LEXO က အလိုအလျောက် OCR လုပ်ပေးပါတယ်။
- **Zawgyi** - မြန်မာ code point တွေကို Unicode စံနဲ့ မတူဘဲ သုံးထားတာကြောင့် Unicode ဖောင့်တွေနဲ့ ကြည့်ရင် စာသားပုံပျက်နေတတ်ပါတယ်။ LEXO က Zawgyi ကို တိုက်ရိုက် မပြောင်းပေးပါဘူး။

## ဖြေရှင်းနည်း ၁ - OCR ဖြင့် စာမျက်နှာကို ဖတ်ပါ

အလွယ်ဆုံးနည်းက Text layer အစား မျက်နှာပြင်ပေါ်မှာ မြင်ရတဲ့ စာမျက်နှာပုံကို ဖတ်ယူတာ ဖြစ်ပါတယ်။ LEXO မှာ **Google Docs OCR** ကို ရွေးပြီး **Run** နှိပ်ပါ။ LEXO က စာမျက်နှာကို ပုံအဖြစ် ပြောင်းပေးပြီး Google Docs OCR က မြန်မာစာကို ဖတ်ကာ Unicode စာသားအဖြစ် ထုတ်ပေးပါတယ်။

Command Line မှဆိုရင် ASCII Layer ကို ကျော်ရန် စာမျက်နှာအားလုံးကို OCR လုပ်ပါ -

```bash
lexo ocr document.pdf --force-ocr -o document.txt
```

အခြား OCR ရလဒ်တွေလိုပဲ စစ်ဆေးဖို့ လိုပါတယ်။ ဒါကြောင့် မူရင်းစာမျက်နှာပုံနဲ့ စာသားကို ယှဉ်တွဲပြထားတာ ဖြစ်ပါတယ်။
